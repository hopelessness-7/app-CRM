# 🚀 app‑CRM

> Полнофункциональный CRM‑сервис на Laravel с поддержкой Docker

## 📋 О проекте

`app-CRM` — это CRM‑система, разработанная на базе Laravel. Основная цель — предоставить удобные инструменты для управления клиентами, сделками и общими бизнес‑процессами. Поддерживает Docker‑окружение для быстрого запуска и консистентного развёртывания.

## ⚙️ Стек технологий

- **Backend**: PHP 8+, Laravel (MVC, Eloquent ORM, миграции, сиди)
- **Frontend**: Vue
- **База данных**: MySQL / MariaDB (через Laravel Schema)
- **Контейнеризация**: Docker, docker-compose
- **Тестирование**: PHPUnit (unit/integration тесты)
- **Дополнительно**: Логирование, job‑планирование (через Laravel Scheduler и очередь)

## 📝 Примечание

> Разработка проекта временно приостановлена. Возможное продолжение — по мере появления ресурсов и времени.
